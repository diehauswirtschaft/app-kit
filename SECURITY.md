# Security

Do not report credentials, personal data, exploitable details or private protocol contents in public issues. Contact the diehauswirtschaft repository maintainers privately (GitHub private vulnerability reporting where enabled).

This is a pre-release library. Authenticates only through the documented Keycloak profile. Supported deployment versions will be declared after pilot acceptance; no production certification is implied by passing unit tests.

Before publication/rollout enable GitHub secret scanning/push protection, dependency alerts and CodeQL where available. All test credentials are generated at runtime. Proprietary fonts and application data do not belong in this repository.
